# Arduino_posture_sensor
An arduino nano posture sensor made to beep when you slouch for over 3 seconds
When you turn it on it sets the current angle as the "correct posture" if the mpu 6050 sensor picks up a deviation of over 15 degress for more than 3 seconds it beeps until it 
detects the correct angle 
this was my first electronics project that is actually usable i had help from claude for the code and connections as it was my first time working with embedded systems
the arduino on my sensor recieves power from a battery however you can also use a USB and connect it to a pc or use a power bank.
Tip for arduino in general if you use a battery as a power source if you ever want to connect it to the pc to change the code don't forget to unplug the battery.
